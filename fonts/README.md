# fonts/

Bundled font files for PF2e Words of Magic. All fonts are pre-registered in `module.json`
and declared in `styles/pf2e-words-of-magic.css` — no configuration needed.

| File | Family Name | Default For |
|---|---|---|
| UltimaRunes.ttf | Ultima Runes | Arcane |
| OuterRimAF.otf | Outer Rim AF | Primal |
| Celestial.ttf | Celestial | Divine |
| CthulhuRunes.ttf | Cthulhu Runes | Occult |
| IokharicBold.otf | Iokharic Bold | Dark Divine |
| Iokharic.otf | Iokharic | Available |
| DaedaBold.otf | Daedra Bold | Available |
| Daedra.otf | Daedra | Available |
| MageScriptBold.otf | Mage Script Bold | Available |
| MageScript.otf | Mage Script | Available |
| MarasEye.ttf | Mara's Eye | Available |
| DrennsRunes.ttf | Drenn's Runes | Available |
| UnownRunes.ttf | Unown Runes | Available |
| Runas.ttf | Runas | Available |

To use a custom font, go to **Settings → Module Settings → PF2e Words of Magic → Configure Fonts**
and browse to any font file in your Foundry data directory.
